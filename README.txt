DROPZONE — обновлённая версия

В этой сборке:
- новым аккаунтам выдаётся стартовый баланс 1000 монет;
- вкладка Marketplace заменена на график Price Growth;
- исправлено отображение рулетки кейса;
- после получения предмета инвентарь обновляется;
- добавлена история изменения цен предметов.

ВАЖНО: этот комплект использует Netlify Functions и Netlify Blobs.
Он не является готовой сборкой для Cloudflare Workers/Pages. Если развернуть его
в Cloudflare как обычный статический сайт, серверные функции и сохранение данных
не заработают. Для полноценного переноса на Cloudflare нужно отдельно перенести
API и хранилище данных.

Для Netlify: загрузите содержимое папки в корень репозитория проекта и выполните
деплой. Не публикуйте секреты и пароли в исходниках; задайте ADMIN_PASSWORD и
SESSION_SECRET в настройках переменных окружения Netlify.
